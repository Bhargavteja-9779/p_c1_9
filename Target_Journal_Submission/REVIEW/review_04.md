# Review 04: R4-statistics

**Recommendation:** major_revision

**Summary:** The central empirical effects are real and reproduce when recomputed correctly (the invariance violation, the SORB train-aug reduction, and the semi-synthetic shortcut all survive a proper dataset-level analysis), so no headline claim collapses. However, the statistical reporting has serious, fixable defects: the headline SORB p-values are pseudoreplicated (dataset x model x feat pooled and mislabeled as "datasets," inflating significance by ~5 orders of magnitude); the multiplicity correction and the Friedman/Nemenyi critical-difference analysis that the Methods and Section 8 explicitly claim are never actually computed (the functions are exercised only in unit tests); the seed count is misstated ("five" vs the actual three) and the stated primary test is mathematically incapable of significance at that n and is not the test that was run; and promised bootstrap CIs for headline differences are absent. These are major-revision issues of rigor and honest reporting, not fabrication of the underlying signal.

## Findings

### [MAJOR] Unit of analysis / pseudoreplication in headline SORB tests
- **Issue:** The pooled SORB results cited in the abstract and Section 7.1 (e.g. 'median change ... -0.0001 in RMSE (improved on 50% of datasets; Wilcoxon p=0.8)' and the RQ4_method_pooled entries, n=160 for regression, n=36 for classification) come from method_pooled() in src/visualization/analyze.py, which groups by ['dataset','model','feat'] and runs ONE paired Wilcoxon treating all 160 cells as independent. Each of the 40 regression datasets appears 4 times (2 models x 2 featurizations); these 4 rows are strongly correlated, so n is not 160. The text and metrics.json describe these as 'datasets' / '% of datasets'. Recomputing at the correct dataset level (averaging model x feat first, n=40) changes sorb_trainaug from p=5.1e-8 to p=5.6e-3 and frac improved from 0.319 to 0.20 - about five orders of magnitude of inflation. The non-significant pooled results happen to be conservative, but every supportive p-value is anti-conservative.
- **Evidence:** method_pooled() (analyze.py L183-197) does base/vv = g[...].groupby(['dataset','model','feat'])[metric].mean() then a single paired_wilcoxon over the concatenated index. Verified: reg sorb_trainaug POOLED n=160,p=5.14e-8 vs DATASET-level n=40,p=5.58e-3. metrics.json RQ4_method_pooled reports n=160/36; manuscript 7.1 calls these 'datasets'.
- **Fix:** Make the dataset the unit of analysis. Either (a) average over model/featurization to one value per dataset and test across datasets (n=40 reg, n=9 clf), or (b) keep model/feat separate and report per-cell tests (as rq4_method already does, n=40 or n=9) without pooling them into one Wilcoxon, or (c) use a mixed-effects model with dataset as a random effect. Re-state every 'X% of datasets' and every pooled p-value with the correct n, and relabel n=160/36 as cells, not datasets.
- **Requires new experiment:** False

### [MAJOR] Multiple-comparison correction claimed but never applied
- **Issue:** Section 5 states 'we ... apply Holm-Bonferroni/Benjamini-Hochberg corrections for multiplicity.' No reported p-value anywhere is corrected. holm_bonferroni() exists in src/stat_tests/compare.py but is called only in tests/test_pipeline.py, never in analyze.py. The RQ4 table alone reports 24 Wilcoxon tests, plus 8 invariance tests, plus the pooled and shortcut tests, all raw. Several 'significant' results (e.g. the ecfp sorb_trainaug reg p=5.8e-6, linear-ecfp clf p=0.012) would be scrutinized differently under correction over the full family of tests.
- **Evidence:** grep across src/ and scripts/ finds holm_bonferroni/benjamini/multipletests/fdr only in the function definition and in a unit test; analyze.py (which the header says produces 'every number cited in the manuscript') never calls it. statistics.json RQ4_method_table wilcoxon_p values are raw.
- **Fix:** Either actually apply Holm-Bonferroni/BH across the declared family of tests and report both raw and adjusted p-values, or remove the correction claim from Section 5 and reframe the per-cell p-values as descriptive. Define the test family explicitly.
- **Requires new experiment:** False

### [MAJOR] Friedman/Nemenyi critical-difference analysis claimed but not performed
- **Issue:** Section 5 claims 'across datasets we use the Friedman test with Nemenyi critical-difference analysis,' and Section 8 claims 'multi-dataset Friedman/Nemenyi analysis supporting the method-level conclusions (Supporting Information, Figures S1-S4).' Neither friedman() nor nemenyi_cd() is ever called in the analysis or figure pipeline (only in a unit test), no critical-difference numbers appear in metrics.json/statistics.json, and no S1-S4 / CD-diagram figures exist in the figures directory. The method-level conclusions are therefore 'supported' by an analysis that was never run.
- **Evidence:** grep for friedman(/nemenyi_cd( outside definitions returns only tests/test_pipeline.py L41-42. figures/ contains fig_invariance_by_representation, fig_operation_ablation, fig_silent_contrast, fig_method_effect, fig1_concept - no CD diagram and no S1-S4. figures.py/tables.py contain no friedman/nemenyi/critical-difference code.
- **Fix:** Compute the Friedman omnibus plus Nemenyi CD across datasets for the SORB variants (the helpers already exist) and generate the SI figures, OR delete the Friedman/Nemenyi and 'Figures S1-S4' claims. Do not cite analyses that are not in the artifact.
- **Requires new experiment:** False

### [MAJOR] Seed count misreported; stated primary test underpowered and not the test actually run
- **Issue:** Section 5 says 'Each configuration is run with five seeds,' but all result CSVs contain exactly 3 seeds (0,1,2); Section 7.1 separately says 'three seeds,' an internal contradiction, and the pre-registration specified R=5 for the grid and R=10 for headline SORB/RQ2. Worse, Section 5's stated primary test, 'Per-dataset paired comparisons across seeds use the Wilcoxon signed-rank test,' is mathematically incapable of rejecting at alpha=0.05 with 3 seeds (the minimum two-sided signed-rank p at n=3 is 0.25; at n=5 it is 0.0625), and it is not the test actually performed: analyze.py averages over seeds (ds_mean = wide.groupby(level=0).mean()) and then tests ACROSS datasets. The reported uncertainty therefore reflects neither the claimed seed-level test nor the pre-registered replicate count.
- **Evidence:** method_results.csv, raw_results.csv, shortcut_results.csv all have seed in {0,1,2}. rq4_method() (analyze.py L104-116) does groupby seeds .mean() then paired_wilcoxon across datasets. research_plan.md L122 specifies R=5 (grid) / R=10 (headline). Manuscript L207 'five seeds' vs L273 'three seeds'.
- **Fix:** Run the pre-registered 5 (and 10 for headline) seeds, or explicitly justify and consistently state 3 seeds throughout. Correct Section 5 to describe the test actually used (seed-averaged per-dataset estimates compared across datasets) and drop the impossible 'per-dataset across-seeds Wilcoxon' description. State the unit of analysis unambiguously.
- **Requires new experiment:** True

### [MODERATE] Promised bootstrap CIs missing for all headline numbers
- **Issue:** Section 5 promises 'bootstrap 95% confidence intervals for headline differences,' but the headline quantities in the text carry no CI: the 0.42x and 0.10x orbit-SD effects (6.4), the 36% train-aug reduction (7.1), the 0.102 shortcut drop and -0.003 SORB value (7.3). Bootstrap CIs are computed only inside the per-cell RQ4 accuracy table (ci_lo/ci_hi feeding Table 3), not for the quantities the paper actually headlines.
- **Evidence:** bootstrap_ci is called only in rq4_method() (analyze.py L117). metrics.json RQ5_invariance, RQ4_method_pooled.trainaug_invariance, and RQ5b_shortcut report point medians/means with no interval. Manuscript body text for 6.4/7.1/7.3 contains no CIs.
- **Fix:** Report bootstrap 95% CIs (dataset-level resampling) for the invariance magnitudes (per representation), the train-aug relative reduction, and the shortcut drop, alongside each headline point estimate.
- **Requires new experiment:** False

### [MODERATE] Shortcut headline p=5e-10 over-interpreted and under-disclosed
- **Issue:** Section 7.3 reports 'paired Wilcoxon p = 5e-10' for the shortcut result. This p is RQ5b_shortcut.baseline_vs_sorb_shortcut_wilcoxon_p, computed over n=49 datasets after averaging two models (lgbm, linear) into one value per dataset, and the shortcut experiment used only the ecfp featurization - none of which is disclosed. A Wilcoxon p at n=49 essentially only certifies that the sign is consistent; reporting it to 10-figure precision with no effect size and no CI overstates what the test establishes, and the sentence attaches the p to 'SORB ... is unaffected (-0.003)' when the test actually concerns baseline-vs-SORB difference. The effect itself is genuine (per-model: lgbm p=2.2e-9, linear p=2.3e-6), so this is a reporting/disclosure issue, not a false positive.
- **Evidence:** rq5b_shortcut() (analyze.py L160-180) pools sc.groupby('dataset').mean() over models; shortcut_results.csv feat column is ecfp only, models {lgbm,linear}. metrics.json RQ5b_shortcut p=5.04e-10, n_datasets=49.
- **Fix:** Report the shortcut effect size (median drop with bootstrap CI) as the headline, present p at reasonable precision (e.g. p<1e-4), disclose that the experiment is ecfp-only and that models were averaged (and show per-model results), and fix the sentence so the p-value is attached to the baseline-vs-SORB contrast it actually tests.
- **Requires new experiment:** False

### [MODERATE] Seed (Monte Carlo) variance not propagated
- **Issue:** Across-dataset tests treat each dataset's estimate (a mean over only 3 seeds) as a fixed, noise-free value; the within-dataset seed variance is discarded rather than propagated. With only 3 scaffold-resplit seeds the per-dataset point estimate is itself noisy, so the across-dataset Wilcoxon/CI understate true uncertainty, and small median deltas such as the testorbit -0.0001 RMSE and the -0.013 trainaug median are within plausible seed noise.
- **Evidence:** analyze.py collapses seeds with .mean() before every inferential test (rq4_method L107, rq5_invariance L139, method_pooled L189-191); no seed-level variance component or hierarchical model is used. Only 3 seeds per cell in method_results.csv.
- **Fix:** Report per-dataset seed variability (e.g. seed-level SD or a per-dataset CI), or use a hierarchical/mixed model with seed nested in dataset; at minimum, show that headline deltas exceed seed noise. Increasing to the pre-registered seed count would materially help.
- **Requires new experiment:** False

### [MINOR] Misstatement of the smallest effect size
- **Issue:** Section 6.4 and the abstract state the violation is 'smallest for gradient-boosted trees on fingerprints (0.12x of the label SD).' 0.12 (lgbm-ecfp) is not the smallest of the four representations reported: linear-desc is 0.072 and lgbm-desc is 0.084, both smaller. A reader comparing to Figure 2 would see the contradiction.
- **Evidence:** metrics.json RQ5_invariance.baseline_invariance_by_representation: lgbm-desc 0.0843, lgbm-ecfp 0.1191, linear-desc 0.0715, linear-ecfp 0.4247.
- **Fix:** Scope the claim to fingerprint featurizations ('among fingerprint models, smallest for trees at 0.12x and largest for linear at 0.42x') or state that the overall smallest is the descriptor representations (~0.07-0.08x).
- **Requires new experiment:** False

### [MINOR] Recurring unit-of-analysis mislabeling and dataset-count overclaim
- **Issue:** Several '% of datasets' statements use cell counts, not dataset counts: Section 6.3 '5% of datasets' is 0.0545 over n=110 dataset x feat cells (55 datasets), and Section 7.1 '50% of datasets' is over n=160 cells. Section 8 claims the findings hold 'across the 55 datasets,' but the SORB/method and shortcut experiments ran on only 49 datasets (classification n=9, not the 13 TDC classification sets implied), which Section 7/8 does not make clear.
- **Evidence:** rq2_ranking groups by ['dataset','task','feat'] -> metrics.json RQ2 n_datasets=110; RQ4 pooled n=160; method_results.csv has 40 reg + 9 clf = 49 datasets. Manuscript L312 'across the 55 datasets'.
- **Fix:** Report fractions over the true number of datasets (or clearly label the denominator as cells), and state in Sections 7-8 that SORB/shortcut results are on the 49 datasets <=6000 molecules (9 classification), not all 55.
- **Requires new experiment:** False

### [MINOR] Effect-size reporting mismatch (rank-biserial vs Cohen's d_z)
- **Issue:** Section 5 says Wilcoxon tests are reported 'with rank-biserial effect sizes,' but the output tables report Cohen's d_z instead and never surface rank-biserial. Additionally, the rank-biserial computed in paired_wilcoxon uses scipy's two-sided statistic (which returns min(W+,W-)), so rb = 1 - 2r/total is always >=0 and loses the sign of the effect - harmless here only because it is never reported.
- **Evidence:** compare.py L22-27 uses res.statistic from stats.wilcoxon(..., alternative='two-sided'); statistics.json RQ4_method_table reports cohen_dz, not rank_biserial.
- **Fix:** Either report rank-biserial (computed with a signed convention) as stated, or change Section 5 to say Cohen's d_z is the reported effect size. Fix the rb sign if it is ever surfaced.
- **Requires new experiment:** False
